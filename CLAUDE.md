# CLAUDE.md

This repo is the post box: a local mailbox that lets AI coding sessions message each other. Read [AGENTS.md](AGENTS.md) first: it has the exact install commands, how to check that it works, how to send, receive and reply, what `delivered`, `queued`, `held` and `refused` mean, how to enable other doors, and the one security rule (NATS listens on `127.0.0.1` only and every client logs in; never change that).
